## Описание

Добавление интерактивного скрипта на страницу из предыдущих лабораторных работ. Скрипт реализует базовые конструкции JavaScript: ввод/вывод данных, условные операторы, циклы и функции для обработки массива.

## Что реализовано

### Ввод / Вывод
- `prompt` — запрашивает имя пользователя при загрузке страницы.
- `alert` — выводит приветствие и результаты анализа.
- `console.log` — выводит подробную информацию (исходные данные, количество тихих треков, предупреждение).

### Данные
Массив из 7 чисел — громкость треков в дБ (от 70 до 110):
`[72, 85, 95, 68, 105, 80, 78]`

### Функции
- `FindMax(arr)` — находит максимальный элемент массива (самый громкий трек).
- `FilterLoud(arr)` — фильтрует массив, оставляя только треки громче 90 дБ.
- `Summa(arr)` — вычисляет сумму всех элементов массива.

### Логика (Циклы и условия)
- Цикл `for` для подсчёта количества тихих треков (≤ 75 дБ) и их суммарной громкости.
- Условная конструкция `if` для проверки, не превышает ли максимальная громкость 105 дБ (предупреждение о слухе).

### Вывод данных
- В `alert`: «Средняя громкость – X дБ, Y треков – громкие».
- В `console.log`: количество тихих треков и их средняя громкость.
- Дополнительное предупреждение в консоль, если громкость ≥ 105 дБ.
